# HTML e CSS

Repositório de estudos e exercícios voltados ao desenvolvimento de páginas web utilizando HTML e CSS.

O objetivo é reunir práticas de estruturação de páginas, estilização e construção de interfaces, acompanhando a evolução dos conhecimentos em desenvolvimento web.

## Conteúdo

- Fundamentos de HTML
- Estrutura semântica de páginas
- Formulários e elementos HTML
- Seletores e propriedades CSS
- Box Model
- Tipografia e estilização
- Flexbox
- CSS Grid
- Layouts responsivos
- Exercícios e projetos práticos

## Tecnologias

- HTML5
- CSS3

## Como utilizar

Clone o repositório:

```bash
git clone https://github.com/bispobr/html-css.git
cd html-css
```

Como o repositório reúne diferentes exercícios e projetos, cada diretório pode possuir sua própria estrutura e forma de execução.

Para visualizar uma página HTML, abra o arquivo `.html` diretamente no navegador ou utilize uma extensão de servidor local no editor de sua preferência.

## Estrutura

A organização pode variar conforme os exercícios e projetos adicionados ao repositório. Os conteúdos são mantidos de forma independente para facilitar o estudo e a evolução gradual dos conceitos.

## Objetivo

Praticar os fundamentos do desenvolvimento front-end, evoluindo desde a estruturação de documentos HTML até a criação de layouts e interfaces utilizando CSS.

## Status

Repositório de estudos e projetos HTML/CSS em evolução contínua.
